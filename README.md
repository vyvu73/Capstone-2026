# Personal Site — Launch School Capstone

Two independent projects, each in its own folder. They share no code and no
dependencies; pick one and run it.

**You need:** [Node.js](https://nodejs.org/) 18 or newer. Nothing else — no
database, no Docker, no global installs.

| Folder | What it is | Start it with | Then open |
|---|---|---|---|
| [`static_page/`](static_page/) | A personal site. One hand-written HTML file. | `npm start` | <http://localhost:3000> |
| [`dynamic_page/`](dynamic_page/) | A 60-second typing speed test. React + Express. | `npm install` then `npm run dev` | <http://localhost:3000> |

## Quick start

```bash
# The personal site — no install step, there are no dependencies
cd static_page
npm start

# The typing test
cd dynamic_page
npm install
npm run dev
```

Both serve on port **3000**, so run them one at a time.
